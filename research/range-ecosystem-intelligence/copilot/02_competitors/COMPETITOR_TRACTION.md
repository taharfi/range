# Competitor Traction Evidence

**Reviewed:** 2026-10-21

## Evidence classification

The public evidence collected in this phase is mostly product documentation, directory presence, public repositories and links. These are **indirect signals**, not verified user counts. Underlying protocol TVL, social followers and directory inclusion must not be presented as third-party product adoption.

| Product | Traction signal | Classification | What is not established |
|---|---|---|---|
| LP Agent | Public product/docs, API portal, DeFiLlama link and paid API tiers | Indirect signal | Active customers, retention, revenue and attributable TVL |
| MetEngine | Multiple live distribution surfaces and Data Agent documentation | Indirect signal | Users, API volume, execution success and revenue |
| Meridian | Public site and active-looking public repository link | Indirect/developer signal | Production users, managed capital and safety |
| LP Army tools directory | 17 named listings captured | Discovery signal | Usage or quality certification |
| Meteora Dynamic Terminal | Official product and protocol documentation | Protocol/product signal | Terminal-specific users and attributable retention |
| Kamino | Official liquidity-vault documentation | Protocol/product signal | Vault-specific current adoption in this report |
| Revert | Detailed public methodology | Product/documentation signal | Solana market adoption |

## Adoption research requirements

The next adoption pass should use product-specific contracts, tagged addresses or official reports where available. It should not use Meteora/Jupiter aggregate volume as a proxy for RANGE or competitor users. A comparable table should record measurement date, chain, contract scope, inclusion rules and whether the metric is product-specific.

## Current conclusion

No defensible numerical competitor ranking was produced. The strongest evidence of market activity is the number and diversity of public products, not a verified ranking of users or revenue.
