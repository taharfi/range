# Funding and Partnership Opportunities

**Reviewed:** 2026-10-21

## Verified public routes

- The [Solana Foundation funding page](https://solana.org/grants-funding) describes hackathons run with Colosseum and ecosystem grant programs, including Superteam microgrants. It does not establish that a specific RANGE application is eligible or currently open.
- The [Solana hackathons page](https://solana.com/hackathons) directs builders to the current hackathon site. Event dates and sponsor tracks must be checked at submission time.
- Meteora's public documentation exposes developer support, Discord, API/SDK resources, community channels and campaigns, but this research did not verify a dedicated 2026 Meteora developer grant.
- No official Jupiter grant or partnership for RANGE was verified. Jupiter integration should be framed as technical ecosystem value, not endorsement.

## Partnership thesis

RANGE can present measurable, testable value:

1. More transparent LP onboarding and risk communication for Meteora.
2. Quote-aware decision handoff that uses Jupiter without unnecessary turnover.
3. Read-only analytics and evidence artifacts that help LPs evaluate positions.
4. Feedback on API fields, data gaps and user workflow friction.

Claims about retention, productive liquidity or incremental routed volume require pilot measurement.

## Recommended outreach sequence

1. Validate the decision brief with LPs and record anonymized outcomes.
2. Share a concise methodology and limitation report with Meteora/Jupiter ecosystem contacts.
3. Ask for technical feedback or distribution, not implied endorsement.
4. Pursue currently listed Solana/Colosseum/Superteam opportunities only after checking live rules, dates and eligibility.
